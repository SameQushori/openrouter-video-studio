# Разработка

1. Создайте отдельную ветку.
2. Используйте `DEMO_MODE=true` для UI и жизненного цикла задач без расходов.
3. После изменений выполните `npm run check`.
4. Не добавляйте `.env`, `data/`, `wrangler.user.jsonc`, загруженные медиа или сторонние бинарники.
5. Платную OpenRouter-проверку описывайте отдельно и запускайте только осознанно.

Dev-режим:

```sh
npm ci
cp .env.example .env
npm run dev
```

Frontend: `http://127.0.0.1:5173`. Backend: `http://127.0.0.1:3001`.

При добавлении capability укажите точный model ID и ссылку на документацию в `server/reference-overrides.json`. Не определяйте поддержку по названию модели только в React UI.
