# Безопасность

## Секреты

- OpenRouter key хранится только в `.env` на компьютере пользователя.
- Media Worker использует отдельный случайный upload secret.
- `.env`, пользовательский Wrangler config и `data/` исключены из Git и Docker build context.
- Перед публикацией выполняйте `npm run check:public`.

Если секрет попал в commit, немедленно отзовите его в соответствующем сервисе. Одного удаления строки из следующего commit недостаточно.

## Доступ

Studio рассчитана на localhost и не имеет пользовательской авторизации. Не выставляйте порт Express в публичный интернет. Docker Compose публикует его только на `127.0.0.1`.

Временный Media Worker предназначен только для материалов, которые пользователь собирается передать выбранному AI-провайдеру. Ссылки содержат случайный UUID, но не заменяют полноценную приватную авторизацию.

## Отчёты

Не прикладывайте к публичному issue API keys, `.env`, приватные видео, содержимое `data/` или полные логи с чувствительными URL. Опишите воспроизведение с demo-режимом, если это возможно.
